# Jotapé Marketing

Site institucional (landing page) da Jotapé Marketing.

## Como funciona

O site fica no arquivo `index.html`. É só abrir esse arquivo no navegador para ver a página.

## Como publicar

1. Faça o deploy do projeto (botão **Publish** no v0 ou conecte o repositório à Vercel).
2. A Vercel detecta o `index.html` automaticamente e publica o site.
